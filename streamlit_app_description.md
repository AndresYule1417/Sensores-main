# 🐓 Sistema Monitoreo Galpón Avícola IoT

Dashboard en tiempo real para monitoreo de sensores ESP8266 en galpones avícolas.

## 🚀 Demo en Vivo
- **Streamlit Cloud**: [Ver Dashboard](https://share.streamlit.io/andresyule1417/sensores-main/main/frontend_dashboard_v3.py)

## 📊 Características
- ✅ Monitoreo tiempo real ESP8266
- ✅ Dashboard interactivo con gráficos
- ✅ Sistema de alertas configurable
- ✅ Análisis histórico de datos
- ✅ Auto-refresh inteligente

## 🏗️ Arquitectura
```
ESP8266 → MQTT → SQLite → FastAPI → Streamlit
```
